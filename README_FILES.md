# 📦 ФАЙЛЫ ДЛЯ СБОРКИ APK

## ✅ Что вам дано:

Этот набор файлов позволяет превратить веб-приложение в APK для Android за несколько минут.

---

## 📄 ОПИСАНИЕ ФАЙЛОВ

### 1. **index.html** - ГЛАВНОЕ ПРИЛОЖЕНИЕ
- Ваше веб-приложение с переводчиком голоса в язык жестов
- Содержит всю логику, стили и анимации
- Работает в браузере И в мобильном приложении

### 2. **config.xml** - КОНФИГУРАЦИЯ CORDOVA
- Описывает приложение (название, версия, разработчик)
- Определяет права доступа (микрофон, интернет и т.д.)
- Настраивает плагины
- **Не изменяйте этот файл** - он уже готов

### 3. **AndroidManifest.xml** - ПРАВА ANDROID
- Указывает системе Android, какие разрешения нужны
- Разрешает доступ к микрофону (`RECORD_AUDIO`)
- Разрешает интернет для облачного распознавания речи
- **Обычно подставляется автоматически** при сборке

### 4. **package.json** - ЗАВИСИМОСТИ
- Список всех требуемых библиотек и плагинов
- Версии компонентов
- Скрипты для сборки
- Используется при локальной сборке через Node.js

### 5. **APK_BUILD_GUIDE.md** - КРАТКАЯ ИНСТРУКЦИЯ
- Краткое описание трёх способов сборки APK
- Для нетерпеливых пользователей

### 6. **FULL_SETUP_GUIDE.md** - ПОДРОБНАЯ ИНСТРУКЦИЯ
- Полное пошаговое руководство
- С картинками для каждого шага (можете добавить)
- Решение проблем
- Рекомендации

---

## 🚀 БЫСТРЫЙ СТАРТ (5 минут)

### Если вы спешите - следуйте этому:

1. **Скачайте файлы:**
   - `index.html`
   - `config.xml`

2. **Создайте папку на компьютере:**
   ```
   sign-language-app/
   ├── index.html
   └── config.xml
   ```

3. **Упакуйте в ZIP** (правый клик → "Отправить" → "Сжатая папка")

4. **Загрузите на https://build.phonegap.com/**
   - Sign Up (бесплатно)
   - New App
   - Upload ZIP
   - Build (Android)
   - Скачайте APK

5. **Установите на телефон**
   - Отправьте APK себе на телефон
   - Откройте и установите
   - Готово!

**Время: 10 минут максимум** ⏱️

## 💡 ПОЯСНЕНИЯ

### Что такое APK?
- Android Package - это исполняемый файл для Android
- Работает как .exe на Windows
- Устанавливается одним кликом

### Что такое Cordova?
- Фреймворк, который оборачивает веб-приложение в нативное
- Даёт доступ к системным функциям (микрофон, камера и т.д.)
- Позволяет запустить JavaScript код как приложение

### Почему PhoneGap Build?
- Это облачный сервис для сборки APK
- Не нужно ничего устанавливать на компьютер
- Сборка занимает 2-5 минут
- Работает в браузере

## ❓ ЧАСТЫЕ ВОПРОСЫ

### Q: Нужно ли платить?
A: Нет! Всё абсолютно бесплатно:
- PhoneGap Build - бесплатный сервис
- Cordova - открытый исходный код
- Android Studio - бесплатно

### Q: Какой размер APK?
A: Обычно 10-20 MB (не критично для современных телефонов)

### Q: Сколько времени на сборку?
A: PhoneGap Build - 2-5 минут
   Локальная - 5-10 минут при первой сборке

### Q: Можно ли опубликовать в Google Play Store?
A: Да! После сборки нужно:
1. Создать аккаунт разработчика ($25)
2. Подписать APK сертификатом
3. Загрузить в Google Play
4. Ждать модерации (24-48 часов)

### Q: Микрофон не работает?
A: Проверьте:
1. config.xml содержит разрешение на микрофон
2. В настройках приложения на телефоне разрешен доступ к микрофону
3. Микрофон включен и работает в других приложениях

### Q: Как обновить приложение?
A: 
1. Отредактируйте index.html
2. Соберите APK заново
3. Установите новую версию (старая удалится)
